# References

The sources this work relied on are listed in `sources.json` and
`apple-shortcuts-event-triggers-source.json`, each with the URL it was fetched
from and a SHA-256 of the copy that was read. The copies themselves are not
redistributed here; fetch them from the URLs, which are pinned to a revision
where the source is a git repository.

Notes elsewhere in this repo that name files such as `references/protocol.rs`
or `references/noop-PROTOCOL_ALARMS.md` refer to those copies.
